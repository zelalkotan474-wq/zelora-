1. İnternet, web sitesi ve tarayıcı nedir?

Web geliştirmeyi öğrenmeden önce internette kullandığımız temel kavramları anlamak önemlidir. İnternet, bilgisayarların ve diğer cihazların birbirleriyle iletişim kurmasını sağlayan geniş bir ağ sistemidir. World Wide Web (WWW) ise internet üzerinden erişebildiğimiz web sayfaları ve kaynaklardan oluşur.

Web sitesi nasıl çalışır?

Tarayıcıya bir web adresi yazdığında tarayıcı ilgili sunucuya istek gönderir. Sunucu, istenen sayfanın dosyalarını veya oluşturulmuş içeriğini geri gönderir. Tarayıcı da HTML, CSS ve JavaScript dosyalarını işleyerek sayfayı ekranda gösterir.

İstemci (Client)

Web sitesini isteyen ve görüntüleyen cihaz veya programdır. Örneğin bilgisayarındaki Chrome tarayıcısı.

Sunucu (Server)

Web sitesinin dosyalarını veya verilerini sağlayan bilgisayar ya da hizmettir.

Tarayıcı (Browser)

Web sayfalarını açar ve görüntüler. Chrome, Firefox, Edge ve Safari örnek verilebilir.

URL

Bir web kaynağının adresidir. Örneğin https://example.com bir URL'dir.

Frontend ve backend arasındaki fark

Frontend, kullanıcının ekranda gördüğü ve etkileşim kurduğu kısımdır. HTML, CSS ve JavaScript frontend geliştirmede temel teknolojilerdir.

Backend, sunucu tarafında çalışan; kullanıcı hesapları, veri işleme, yetkilendirme ve veritabanı işlemleri gibi işleri yöneten bölümdür. Backend için JavaScript (Node.js), Python, PHP ve başka teknolojiler kullanılabilir.

Örnek: Bir eğitim sitesinde ders kartlarını görmek frontend ile ilgilidir. Kullanıcının hesabını doğrulamak ve ilerlemesini sunucuda saklamak ise backend ve veritabanı gerektirebilir.

2. HTML nedir?

HTML, “HyperText Markup Language” ifadesinin kısaltmasıdır. Web sayfasının içeriğini ve yapısını tanımlamak için kullanılır. HTML, bir programlama dili değil, işaretleme dilidir. Başlıkların, metinlerin, görsellerin ve bağlantıların sayfada ne olduğunu tarayıcıya anlatır.

İlk HTML sayfamız

Visual Studio Code'da yeni bir dosya aç. Dosyayı ilk-sayfam.html adıyla kaydet. Aşağıdaki kodu içine yaz:

Örnek 1 — HTML iskeleti

<!DOCTYPE html>
<html lang="tr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>İlk Web Sayfam</title>
</head>
<body>
  <h1>Merhaba Dünya!</h1>
  <p>Bu benim ilk web sayfam.</p>
</body>
</html>

Bu kodların anlamı

  • <!DOCTYPE html>: Tarayıcıya belgenin HTML5 standardını kullandığını bildirir.
  • <html lang="tr">: HTML belgesinin başladığını ve sayfanın dilinin Türkçe olduğunu belirtir.
  • <head>: Sayfa başlığı ve karakter kodlaması gibi bilgileri içerir.
  • <meta charset="UTF-8">: Türkçe karakterlerin doğru gösterilmesine yardımcı olur.
  • <meta name="viewport"...>: Sayfanın mobil ekranlarda uygun ölçeklenmesini sağlar.
  • <title>: Tarayıcı sekmesinde görünen başlığı belirler.
  • <body>: Sayfada görünen asıl içeriği barındırır.
  • <h1>: Ana başlığı belirtir.
  • <p>: Paragraf oluşturur.
Uygulama: Dosyayı kaydet. Dosyanın bulunduğu klasörü açıp HTML dosyasına çift tıkla. Tarayıcıda “Merhaba Dünya!” başlığını görmelisin.

3. HTML etiketleri ve içerik oluşturma

HTML'de birçok öğe bir açılış etiketi, içerik ve kapanış etiketiyle yazılır. Örneğin <p>Merhaba</p> bir paragraftır. Bazı etiketlerin kapanış etiketi yoktur; örneğin <img> ve <br>.

Başlıklar ve paragraflar

<h1> en üst düzey başlığı, <h2> alt başlığı, <h3> ise daha alt düzey başlığı ifade eder. Başlıkları sadece yazıyı büyütmek için değil, içeriği mantıklı biçimde düzenlemek için kullanmalısın.

Örnek 2 — Başlık ve metin

<h1>Bilgisayar Eğitimi</h1>
<h2>HTML Öğreniyorum</h2>
<p>HTML web sayfalarının yapısını oluşturur.</p>
<p>Bu ikinci bir paragraftır.</p>
<strong>Önemli metin</strong>
<em>Vurgulanan metin</em>

Bağlantı oluşturmak

<a> etiketi bağlantı oluşturur. Bağlantının hedefi href niteliğiyle belirtilir.

<a href="https://www.example.com">
  Örnek siteyi ziyaret et
</a>

Görsel eklemek

<img> etiketi sayfaya görsel ekler. src görselin adresini, alt ise görseli açıklayan alternatif metni belirtir.

<img src="resim.jpg" alt="Bir bilgisayar masası">

Görsel dosyası HTML dosyanla aynı klasördeyse resim.jpg gibi bir yol kullanabilirsin. Başka bir klasördeyse uygun dosya yolunu belirtmelisin.

Listeler oluşturmak

Sırasız liste

Maddelerin belirli bir sıralaması olmadığında kullanılır.

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Sıralı liste

Maddelerin sıra numarasıyla gösterilmesi gerektiğinde kullanılır.

<ol>
  <li>Dosyayı oluştur</li>
  <li>Kodu yaz</li>
  <li>Tarayıcıda aç</li>
</ol>

Tablo oluşturmak

Tablolar, satır ve sütunlardan oluşan verileri göstermek için kullanılır. Sayfa düzenini oluşturmak için tablo kullanmak yerine CSS düzen araçlarını tercih etmelisin.

<table>
  <tr>
    <th>Ders</th>
    <th>Seviye</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>Başlangıç</td>
  </tr>
</table>

Formlar ve kullanıcıdan bilgi alma

Formlar kullanıcıdan bilgi almak için kullanılır. Örneğin iletişim formu, kayıt formu veya arama kutusu oluşturabilirsin. Ancak HTML ile formu çizmek, girilen bilgileri bir sunucuya kaydetmekle aynı şey değildir. Gerçek veri kaydı için ayrıca uygun bir işlem gerekir.

<form>
  <label for="ad">Adın:</label>
  <input id="ad" name="ad" type="text"
         placeholder="Adını yaz">
  <button type="submit">Gönder</button>
</form>

✍️ Alıştırma

Bir “Kendimi Tanıtıyorum” sayfası oluştur. İçinde bir ana başlık, kendini anlatan iki paragraf, üç maddelik bir hobi listesi ve sevdiğin bir web sitesine bağlantı olsun.

4. CSS nedir?

CSS, “Cascading Style Sheets” ifadesinin kısaltmasıdır. HTML ile oluşturduğun içeriğin görünümünü düzenler. Renkler, yazı tipleri, boyutlar, kenarlıklar, boşluklar, hizalama ve sayfa düzeni CSS ile belirlenebilir.

CSS nasıl eklenir?

CSS üç temel şekilde kullanılabilir:

  • Satır içi CSS: Bir HTML öğesinin style niteliğinde yazılır. Küçük denemelerde kullanılabilir.
  • Dahili CSS: HTML dosyasındaki <style> etiketi içinde yazılır.
  • Harici CSS: Ayrı bir .css dosyasında tutulur. Büyük projelerde düzeni korumayı kolaylaştırır.

CSS dosyasını bağlamak

HTML dosyanın <head> bölümüne aşağıdaki satırı ekleyebilirsin:

<link rel="stylesheet" href="style.css">

Bu örnekte style.css dosyası HTML dosyasıyla aynı klasörde bulunmalıdır.

Örnek 3 — Basit CSS tasarımı

body {
  font-family: Arial, sans-serif;
  background: #f7f5ff;
  color: #25243a;
  margin: 0;
  padding: 30px;
}

h1 {
  color: #7155d9;
  text-align: center;
}

.card {
  max-width: 600px;
  margin: 20px auto;
  padding: 24px;
  background: white;
  border-radius: 16px;
  box-shadow: 0 5px 20px #25243a12;
}

CSS kuralları nasıl okunur?

Bir CSS kuralında önce hangi öğenin seçileceği yazılır. Buna seçici (selector) denir. Süslü parantezlerin içinde o öğeye uygulanacak özellikler ve değerleri bulunur.

p {
  color: purple;
  font-size: 18px;
}

Burada p seçicisi bütün paragraf öğelerini hedefler. color yazı rengini, font-size ise yazı boyutunu belirler.

Sınıf (class) ve kimlik (id)

class, birden fazla HTML öğesinde kullanılabilir. CSS'de nokta ile seçilir. id ise sayfadaki belirli bir öğeyi tanımlamak için kullanılır ve CSS'de diyez işaretiyle seçilir.

/* HTML: <div class="kart">... */
.kart {
  padding: 20px;
}

/* HTML: <section id="hakkimda">... */
#hakkimda {
  background: white;
}

Boşluklar, kenarlıklar ve kutu modeli

CSS'de her öğeyi bir kutu gibi düşünebilirsin. İçerik (content), iç boşluk (padding), kenarlık (border) ve dış boşluk (margin) birlikte kutu modelini oluşturur.

  • padding: İçerikle kenarlık arasındaki boşluk.
  • margin: Öğenin dışındaki boşluk.
  • border: Öğenin kenarlığı.
  • border-radius: Köşeleri yuvarlatır.
  • box-shadow: Gölge ekler.

✍️ Alıştırma

HTML sayfana bir kart ekle. Kartın arka planını beyaz yap, köşelerini yuvarlat, içine 20 piksel boşluk ekle ve başlığını mor renge boya.

5. Sayfa düzeni ve mobil uyumlu tasarım

Bir web sitesi yalnızca bilgisayarda değil, telefon ve tablet ekranlarında da rahat kullanılabilmelidir. Buna responsive (duyarlı) tasarım denir. Responsive tasarımda içerik ekranın genişliğine göre uyum sağlar.

Flexbox ile öğeleri hizalamak

Flexbox, öğeleri bir satır veya sütun boyunca düzenlemeye yardımcı olur. Menüleri, kartları ve buton gruplarını hizalamak için kullanışlıdır.

.menu {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

justify-content ana eksendeki dağılımı, align-items ise diğer eksendeki hizalamayı düzenler. Yön, flex-direction ile değiştirilebilir.

Grid ile sütunlar oluşturmak

CSS Grid, iki boyutlu sayfa düzenleri için uygundur. Örneğin ekran genişken üç kartı yan yana, dar ekranlarda ise tek sütun gösterebilirsin.

.kartlar {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 20px;
}

@media (max-width: 700px) {
  .kartlar {
    grid-template-columns: 1fr;
  }
}

@media kuralı, belirli ekran koşullarında farklı CSS kuralları uygulamayı sağlar.

Mobil uyumluluk için kontrol listesi

  • HTML dosyasında viewport meta etiketi bulunsun.
  • İçerik sabit ve aşırı geniş ölçülere bağlı kalmasın.
  • Metinler telefonda rahat okunabilsin.
  • Butonlar parmakla dokunulabilecek büyüklükte olsun.
  • Görseller ekran dışına taşmasın.
  • Menüler ve formlar küçük ekranlarda da kullanılabilsin.
İpucu: Chrome'da sayfana sağ tıklayıp “İncele” seçeneğini açabilir, cihaz simgesinden farklı ekran boyutlarını deneyebilirsin. Böylece mobil tasarımını test edebilirsin.

6. JavaScript ile sayfaya etkileşim kazandırmak

JavaScript, web sayfalarına davranış kazandıran bir programlama dilidir. Bir butona tıklandığında mesaj göstermek, form girişlerini kontrol etmek, bir hesaplama yapmak veya sayfadaki içeriği değiştirmek için kullanılabilir.

Değişkenler

Değişkenler, program çalışırken kullanacağın verileri isimlerle tutmanı sağlar. Günümüzde değiştirilebilir değerler için genellikle let, yeniden atanmayacak değişkenler için const tercih edilir.

const siteAdi = "ZELORA";
let ziyaretSayisi = 0;

ziyaretSayisi = ziyaretSayisi + 1;

console.log(siteAdi);
console.log(ziyaretSayisi);

Koşullar

if ve else, bir koşulun doğru veya yanlış olmasına göre farklı kodların çalışmasını sağlar.

const puan = 85;

if (puan >= 50) {
  console.log("Başarılı");
} else {
  console.log("Tekrar çalışmalısın");
}

Fonksiyonlar

Fonksiyon, belirli bir işi yapmak üzere yazılmış ve ihtiyaç duyulduğunda çalıştırılabilen kod bloğudur.

function selamVer(isim) {
  return "Merhaba " + isim + "!";
}

console.log(selamVer("Zelal"));

Butona tıklama olayı

Bir olay (event), kullanıcının tıklaması veya klavyeden yazı yazması gibi bir etkileşimdir. JavaScript bu olaylara tepki verebilir.

Örnek 4 — Çalışan buton

<button id="mesajButonu">Bana tıkla</button>
<p id="mesaj"></p>

<script>
  const buton = document.getElementById("mesajButonu");
  const mesaj = document.getElementById("mesaj");

  buton.addEventListener("click", function() {
    mesaj.textContent = "ZELORA'ya hoş geldin!";
  });
</script>

DOM nedir?

DOM, tarayıcının HTML belgesini JavaScript ile erişilebilen bir nesne yapısı olarak sunmasıdır. document.getElementById() belirli bir kimliğe sahip öğeyi bulur. textContent öğenin metnini değiştirebilir.

Diziler ve döngüler

Diziler birden fazla değeri tek bir değişkende saklamaya yarar. Döngüler de bir işlem grubunu tekrar tekrar çalıştırır.

const dersler = ["HTML", "CSS", "JavaScript"];

for (const ders of dersler) {
  console.log(ders);
}

Hataları bulmak

Kod beklediğin gibi çalışmıyorsa tarayıcı geliştirici araçlarındaki Console bölümünü kontrol et. Kırmızı hata mesajları sorunun hangi dosyada veya satırda olduğunu anlamana yardımcı olabilir. Etiketleri kapatmayı, dosya adlarını ve parantezleri kontrol etmeyi unutma.

✍️ Alıştırma

Bir butona tıklandığında sayfada “Bugün web geliştirme öğreniyorum!” mesajı göster. Sonra mesajı kendi cümlenle değiştir.

7. Uygulama projesi: Kişisel tanıtım sayfası

Şimdi öğrendiğin HTML ve CSS bilgilerini küçük bir projede birleştirelim. Bu örnekte başlık, tanıtım yazısı, beceri listesi ve bir bağlantı bulunan sade bir profil kartı oluşturacağız.

Proje kodu

<!DOCTYPE html>
<html lang="tr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Kişisel Sayfam</title>
  <style>
    body {
      margin: 0;
      padding: 30px;
      font-family: Arial, sans-serif;
      background: #f7f5ff;
      color: #25243a;
    }

    .profil {
      max-width: 600px;
      margin: 30px auto;
      padding: 28px;
      background: white;
      border-radius: 18px;
      box-shadow: 0 8px 25px #25243a12;
    }

    h1 { color: #7155d9; }

    .beceri {
      display: inline-block;
      padding: 7px 12px;
      margin: 4px;
      background: #eee9ff;
      border-radius: 20px;
    }

    a { color: #7155d9; }
  </style>
</head>
<body>
  <main class="profil">
    <h1>Merhaba, ben Zelal!</h1>
    <p>Web geliştirmeyi öğreniyorum ve kendi projelerimi yapıyorum.</p>

    <h2>Öğrendiğim konular</h2>
    <span class="beceri">HTML</span>
    <span class="beceri">CSS</span>
    <span class="beceri">JavaScript</span>

    <h2>Hedefim</h2>
    <p>Kullanışlı ve mobil uyumlu web siteleri geliştirmek.</p>

    <a href="https://developer.mozilla.org/">
      Web geliştirme kaynaklarını incele
    </a>
  </main>
</body>
</html>

Projeyi geliştir

  1. Tanıtım metnini kendine göre değiştir.
  2. Yeni bir beceri etiketi ekle.
  3. Arka plan rengini değiştir.
  4. Kartın genişliğini değiştirerek sonucu gözlemle.
  5. Bir buton ekleyip JavaScript ile çalıştırmayı dene.
Önemli: Kodu yeni bir HTML dosyasına kaydet. Örneğin profil-projem.html. Böylece mevcut ZELORA ana sayfanın dosyalarına dokunmadan pratik yapabilirsin.

9. Web sitesi nasıl yayımlanır?

Bilgisayarında oluşturduğun HTML dosyası önce yerel olarak çalışır. Başka kişilerin de internet üzerinden erişebilmesi için sitenin dosyalarını bir web barındırma (hosting) hizmetine yüklemen ve uygun bir adresle yayımlaman gerekir.

Yerel çalışma ve canlı site

Yerel dosya

Bilgisayarındaki HTML dosyasını tarayıcıda açarak tasarımını test edebilirsin. Bu aşamada site herkese açık değildir.

Yayımlanmış site

Dosyalar bir hosting hizmetine yüklendiğinde ve yayımlama işlemi tamamlandığında diğer kişiler sitene internet üzerinden ulaşabilir.

Temel yayımlama adımları

  1. HTML, CSS, JavaScript ve görsel dosyalarını düzenle.
  2. Dosya yollarını ve bağlantıları kontrol et.
  3. Mobil görünümü ve farklı tarayıcıları test et.
  4. Statik siteleri destekleyen bir hosting hizmeti seç.
  5. Dosyalarını hizmetin yönergelerine göre yükle.
  6. Oluşan web adresini açarak siteyi kontrol et.

Ücretsiz hosting seçenekleri bulunabilir; ancak kullanım sınırları ve koşulları değişebilir. Alan adı almak ise ayrı bir ücret gerektirebilir. Yayınlamadan önce seçtiğin hizmetin güncel şartlarını kontrol et.

Güvenlik ve erişilebilirlik

  • Formlardan gelen verileri güvenli şekilde işle.
  • Gereksiz kişisel bilgileri toplama.
  • Görseller için anlamlı alternatif metinler kullan.
  • Başlık sırasını mantıklı tut ve bağlantılara anlaşılır metinler ver.
  • Dosya adlarını ve klasör yapısını düzenli tut.

10. Web geliştirme terimleri sözlüğü

HTML
Web sayfasının yapısını ve içeriğini tanımlayan işaretleme dili.
CSS
Web sayfasının görünümünü ve düzenini belirleyen stil dili.
JavaScript
Web sayfalarına davranış ve etkileşim kazandırmak için kullanılan programlama dili.
Frontend
Kullanıcının tarayıcıda gördüğü ve etkileşim kurduğu bölüm.
Backend
Sunucu tarafındaki işlemleri ve uygulama mantığını yöneten bölüm.
Tarayıcı
Web sayfalarını açıp görüntüleyen program.
Sunucu
İsteklere karşılık web içeriği veya veri sağlayan sistem.
Hosting
Web sitesinin dosyalarını internet üzerinden erişilebilir şekilde barındıran hizmet.
Alan adı (Domain)
Bir web sitesine ulaşmak için kullanılan okunabilir adres.
Responsive tasarım
