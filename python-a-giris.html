2. Python nedir?

Python; web geliştirme, veri analizi, otomasyon, yapay zekâ, bilimsel hesaplamalar ve çeşitli yazılım projelerinde kullanılan genel amaçlı bir programlama dilidir.

Python'ın başlangıç seviyesinde tercih edilmesinin nedenlerinden biri, kodlarının çoğu zaman okunabilir ve anlaşılır olmasıdır. Örneğin, ekrana bir mesaj yazdırmak için tek bir komut kullanabiliriz. 

print("Merhaba Dünya!")

Bu komut çalıştırıldığında ekranda şu sonuç görülür:

Merhaba Dünya!

Python hangi alanlarda kullanılır?

  • Web geliştirme: Web sitelerinin sunucu tarafında çalışan bölümlerini geliştirme.
  • Veri analizi: Büyük miktardaki verileri inceleme ve anlamlı sonuçlar çıkarma.
  • Yapay zekâ: Makine öğrenmesi ve yapay zekâ uygulamaları geliştirme.
  • Otomasyon: Tekrarlanan bilgisayar işlemlerini otomatikleştirme.
  • Eğitim: Algoritma ve programlama mantığını öğrenme.
  • Bilimsel hesaplama: Matematiksel ve bilimsel problemleri çözme.

Programlama dili ne demektir?

Programlama dili, bilgisayara belirli işlemleri yaptırmak için kullandığımız kurallar ve komutlardan oluşur. Bir program yazarken bilgisayara hangi işlemi, hangi sırayla yapacağını tarif ederiz.

Örnek: Bir marketteki ürünlerin fiyatlarını toplamak istiyorsan Python'a fiyatları verebilir ve toplamı hesaplatabilirsin. Daha sonra bu fikri geliştirerek stok veya satış programı oluşturabilirsin.

3. Python nasıl kurulur?

Bilgisayarında Python kodlarını doğrudan çalıştırabilmek için Python yorumlayıcısını kurabilirsin. Kodlarını yazmak için VS Code gibi bir kod düzenleyicisi de kullanabilirsin.

  1. Python'ın resmî indirme sayfasını aç.
  2. İşletim sistemine uygun Python sürümünü indir.
  3. Windows kurulumunda varsa Add Python to PATH seçeneğini işaretle.
  4. Kurulumu tamamla.
  5. VS Code kullanıyorsan Extensions bölümünden Python eklentisini kur.
  6. Bir dosya oluşturup dosyayı merhaba.py adıyla kaydet.

Dosyanın içine aşağıdaki kodu yazabilirsin:

print("Python çalışıyor!")

Terminalden çalıştırmak için çoğu Windows kurulumunda python merhaba.py veya py merhaba.py komutlarından biri kullanılabilir.

Kurulum adımları işletim sistemine ve bilgisayardaki ayarlara göre değişebilir. Python kurulmadan da bu sayfadaki örnekleri okuyabilir ve uygulama alanındaki desteklenen örnekleri deneyebilirsin.

4. İlk Python kodumuz

Programlamaya başlarken sık kullanılan komutlardan biri print() komutudur. Bu komut bir değeri veya mesajı ekranda göstermemizi sağlar. 

print("Merhaba!")
print("ZELORA Python eğitimine hoş geldin.")
print(25)

Çıktı:

Merhaba!
ZELORA Python eğitimine hoş geldin.
25

Metin ve sayı arasındaki fark

Tırnak içinde yazılan "25" bir metindir. Tırnaksız yazılan 25 ise bir tam sayıdır. Bu fark, hesaplama yaparken önem kazanır. 

print(10 + 5)
print("10" + "5")

Sonuç:

15
105

İlk satırda sayılar toplanır. İkinci satırda iki metin yan yana birleştirilir.

Yorum satırları

Yorum satırları, kodu okuyan kişiye açıklama yazmak için kullanılır. Python, # işaretinden sonraki açıklamayı çalıştırmaz. 

# Bu satır bir açıklamadır.
print("Bu satır çalışır.")

5. Değişkenler

Değişkenler, program içerisinde kullanacağımız değerleri isimlerle saklamamıza yardımcı olur. Bir değişkeni, bir bilgiyi saklayan etiketli bir kutu gibi düşünebilirsin. 

isim = "Zelal"
yas = 24
sehir = "Ağrı"

print(isim)
print(yas)
print(sehir)

Burada üç değişken tanımlanmıştır. Python, eşittir işaretinin sağındaki değeri sol taraftaki isimle ilişkilendirir.

Değişken isimlendirme kuralları

  • Değişken isimleri harf veya alt çizgi (_) ile başlayabilir.
  • İsimler rakamla başlayamaz.
  • Boşluk yerine genellikle alt çizgi kullanılır.
  • Python'da büyük ve küçük harfler farklı kabul edilir.
  • if, for ve class gibi ayrılmış kelimeler değişken adı olarak kullanılmamalıdır.
ogrenci_adi = "Ece"
sinav_notu = 90
urun_fiyati = 149.90

print(ogrenci_adi)
print(sinav_notu)
print(urun_fiyati)

Değişkenin değerini değiştirmek

puan = 10
print(puan)

puan = 20
print(puan)

İlk çıktıda 10, ikinci çıktıda 20 görülür. Değişkene yeni bir değer atanmıştır.

Hatırla: = işareti Python'da çoğunlukla atama yapmak için kullanılır. İki değerin eşit olup olmadığını kontrol etmek için == kullanılır.

6. Temel veri tipleri

Programlarda farklı türde bilgilerle çalışırız. Python, değerlerin türlerini tanımamıza yardımcı olan çeşitli veri tiplerine sahiptir.

Veri tipi Açıklama Örnek
str Metin "Merhaba"
int Tam sayı 42
float Ondalıklı sayı 3.14
bool Doğru veya yanlış True, False
list Sıralı, değiştirilebilir koleksiyon [1, 2, 3] 
isim = "Ece"
yas = 22
ortalama = 87.5
mezun_mu = True

print(type(isim))
print(type(yas))
print(type(ortalama))
print(type(mezun_mu))

type() fonksiyonu, verilen değerin türünü gösterir. Bu özellik özellikle kullanıcıdan gelen verilerle çalışırken faydalıdır.

Tür dönüşümü

Bir metni sayıya veya bir sayıyı metne dönüştürmek gerektiğinde int(), float() ve str() gibi fonksiyonlar kullanılabilir. 

sayi_metni = "25"
sayi = int(sayi_metni)

print(sayi + 5)

Çıktı: 30

Sayıya dönüştürülemeyen bir metni int() ile dönüştürmeye çalışırsan hata alabilirsin. Örneğin int("merhaba") geçerli değildir.

yas = 24
ehliyeti_var = True

print(yas >= 18 and ehliyeti_var)

8. Kullanıcıdan veri alma

input() fonksiyonu kullanıcıdan bilgi alır. Kullanıcı bir cevap yazıp Enter tuşuna bastığında bu cevap programda kullanılabilir. 

isim = input("Adın nedir? ")
print("Merhaba", isim)

Önemli bir ayrıntı: input() fonksiyonu varsayılan olarak metin döndürür. Kullanıcıdan sayı almak istiyorsan uygun tür dönüşümünü yapmalısın. 

yas = int(input("Kaç yaşındasın? "))
print("Gelecek yıl yaşın:", yas + 1)

İki sayıyı toplama

sayi1 = float(input("Birinci sayıyı yaz: "))
sayi2 = float(input("İkinci sayıyı yaz: "))

toplam = sayi1 + sayi2

print("Toplam:", toplam)
Güvenli kullanım: Kullanıcıdan gelen verilerin beklenen biçimde olup olmadığını gerçek projelerde kontrol etmek gerekir. Örneğin kullanıcı sayı beklenen yere harf yazarsa hata oluşabilir.

9. Koşullu ifadeler: if, elif, else

Koşullu ifadeler, programın bir duruma göre farklı işlemler yapmasını sağlar. Örneğin bir sınav notu belirli bir değerin üzerindeyse farklı bir mesaj gösterebiliriz. 

notu = 75

if notu >= 50:
    print("Başarılı")
else:
    print("Başarısız")

Python'da koşuldan sonra iki nokta (:) kullanılır. Koşulun içindeki komutlar girintili yazılır. Girintiler, hangi komutun hangi bloğa ait olduğunu belirtir.

Birden fazla koşul

notu = 82

if notu >= 85:
    print("Çok iyi")
elif notu >= 70:
    print("İyi")
elif notu >= 50:
    print("Geçti")
else:
    print("Tekrar çalışmalısın")

Python koşulları sırayla kontrol eder. İlk doğru koşulun bloğunu çalıştırır ve ilgili koşul zincirini tamamlar.

Günlük hayattan örnek

Bir alışveriş sitesinde sepet tutarı 1000 TL'yi geçtiğinde indirim uygulandığını düşün. Program sepet tutarını kontrol edip koşula göre farklı sonuçlar üretebilir. 

sepet = 1200

if sepet >= 1000:
    print("İndirim kazandınız.")
else:
    print("İndirim için sepet tutarını artırın.")

10. Döngüler: for ve while

Döngüler, bir işlemi tekrar tekrar yazmak yerine belirli bir kurala göre tekrarlamamızı sağlar.

For döngüsü

for sayi in range(5):
    print(sayi)

Çıktı:

0
1
2
3
4

range(5), bu örnekte 0'dan başlayıp 5'e ulaşmadan sona eren sayıları üretir. Başlangıç ve bitiş değerlerini de belirtebilirsin: 

for sayi in range(1, 6):
    print(sayi)

Bu kez 1, 2, 3, 4 ve 5 yazdırılır.

While döngüsü

while, koşul doğru olduğu sürece döngüyü çalıştırır. 

sayi = 1

while sayi <= 5:
    print(sayi)
    sayi = sayi + 1
Dikkat: While döngüsünde koşulun bir noktada yanlış hâle gelmesini sağlayacak bir işlem yoksa döngü sonsuza kadar devam edebilir.

Döngüler nerelerde kullanılır?

  • Bir listedeki bütün ürünleri incelemek.
  • Bir sınavdaki öğrenci puanlarını hesaplamak.
  • Belirli sayıda işlem yapmak.
  • Kullanıcıdan doğru bilgi girene kadar tekrar istemek.

11. Listeler

Listeler birden fazla değeri tek bir değişkende saklamamıza yarar. Liste elemanlarına sıfırdan başlayan indeks numaralarıyla ulaşılır. 

meyveler = ["elma", "armut", "muz"]

print(meyveler[0])
print(meyveler[1])

Çıktı:

elma
armut

Listeye eleman ekleme

renkler = ["mor", "mavi"]
renkler.append("yeşil")

print(renkler)

Listede eleman sayısı

sayilar = [10, 20, 30, 40]

print(len(sayilar))

Çıktı: 4

Liste üzerinde döngü kurmak

ogrenciler = ["Ece", "Deniz", "Mert"]

for ogrenci in ogrenciler:
    print(ogrenci)

Listeler; öğrenci isimleri, ürünler, fiyatlar ve benzeri çok sayıda veriyi birlikte tutmak için oldukça kullanışlıdır.

12. Fonksiyonlar

Fonksiyonlar, belirli bir işi gerçekleştiren ve ihtiyaç duyulduğunda çağrılabilen kod bloklarıdır. Tekrar kullanılabilir kod yazmayı kolaylaştırırlar. 

def selamla():
    print("ZELORA eğitimine hoş geldin!")

selamla()

Burada def anahtar kelimesiyle bir fonksiyon tanımlanmıştır. Fonksiyonun içindeki kod, fonksiyon çağrıldığında çalışır.

Parametre alan fonksiyon

def selamla(isim):
    print("Merhaba", isim)

selamla("Ece")
selamla("Mert")

Değer döndüren fonksiyon

def topla(a, b):
    return a + b

sonuc = topla(10, 5)
print(sonuc)

return, fonksiyonun sonucunu çağrıldığı yere geri döndürür. Sonuç daha sonra başka bir hesaplamada da kullanılabilir.

Fonksiyonlar büyüyen projelerde kodun daha düzenli, anlaşılır ve tekrar kullanılabilir olmasına yardımcı olur.

13. Yaygın hatalar ve hata ayıklama

Program yazarken hata almak normaldir. Önemli olan hata mesajını okuyup hangi satırda ve hangi işlem sırasında sorun çıktığını anlamaktır.

SyntaxError — yazım hatası

print("Merhaba"

Parantez kapatılmadığı için Python kodu doğru şekilde yorumlayamaz.

NameError — tanımsız isim

print(ogrenci)

ogrenci isimli bir değişken önceden tanımlanmamışsa Python bu ismi bulamayabilir.

TypeError — uyumsuz veri türleri

yas = 20
print("Yaş: " + yas)

Bu örnekte metin ile tam sayı doğrudan birleştirilmeye çalışılmıştır. Dönüştürme yapabilirsin: 

yas = 20
print("Yaş: " + str(yas))

Hata ayıklamak için öneriler

  1. Hata mesajını dikkatle oku.
  2. Belirtilen satır numarasını kontrol et.
  3. Parantezleri, tırnakları ve iki noktaları incele.
  4. Değişken adlarının doğru yazıldığından emin ol.
  5. Kodu küçük parçalar hâlinde çalıştırarak sorunun kaynağını bul.
